# 已适配 soc 和适配程度列表

表格列说明：

- **SoC**：SoC 型号，如 `msm8917`、`sm8650` 等
- **常见名称**：SoC 常见名称，如 `Snapdragon 425`、`Snapdragon 8 Gen 3` 等
- **适配情况**：
  - **适配** = 已经进入长期支持阶段
  - **测试** = 正在物理机验证
  - **就绪** = 可以运行，目前暂未收到物理机验证日志
  - **计划** = 计划在后续版本中支持
- **累计推理量**：累计参与推理的日志行数
- **帕累托前沿**：是否已适配帕累托前沿概念算法
- **不启用**：是否已禁用该 soc
- **测试设备**：测试设备型号，如 `PHB110`、`Pixel 6` 等

## 未纳入的机型

`freqbench_tensor/results/` 里有数据但**功耗列不可用**，折算不出可信的逐档能效，故不生成配置：

- `t8103`（Apple M1）：燃料计读数恒为 0（`housekeeping.power_mean == 0.0`），逐档功耗全零，量不了动态功耗。
- `mt6768`（Helio G70）：满频簇功耗仅 2.6 mW / 0.5 mW 量级，原始读数被单位缩放过。

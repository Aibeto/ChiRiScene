# SM8850 频率 → 功耗对照（qpt PMIC 逐轨实测）

> 索引：`[source]` `[caliber]` `[efi]` `[limits]`

## 0. 摘要

- **数据源**：`/sys/class/powercap/qpt:*`（Qualcomm Power Telemetry）PMIC 逐轨实测
- **结果**：交叉点 **2.736-2.738 GHz**（与极客湾 2.742 差 <0.3%）；甜点 big **2496 kHz** / prime **3859 kHz**
- **采用**：qpt 实测（`frontier_policy.py` 生成，指纹 9aaf8c9c88c1f823）；极客湾曲线转换作交叉验证（见附录 B）

## 2. [caliber] 折算口径

1. **数据源**：qpt PMIC 逐轨（`qpt:0:0`=cpu-m big / `qpt:0:1`=cpu-l prime）——**纯 CPU 轨**，非整板/电池差分。
2. **测量方法**：隔离测量（后台迁非测簇）+ idle/busy 差分 + 分档冷却；每点 3-10 轮取中位，剔除冻结/回绕/离群轮。
3. **降噪**：V8（3 轮）→ 最新（v7/v8/v10/v11/v14 合并，8-10 轮）——逐点对比见附录 A。
4. **`power_w`** = 簇功耗（idle 簇 + n×单核增量，溯源/遥测用）；**`single_core_power_w`** = 单核功耗（`power_w ÷ 核数`）——运行期 `energy_model` **只消费 `single_core_power_w`**。
5. **无 `voltage_mv`**：不反解 Cx（不编造电压）。
6. **capacity 与算力**：
   - `capacity` = sysfs `cpu_capacity`（实测：762/1024）
   - **算力（相对）** = `capacity × f / f_max`（f_max = 簇最高档：big 3628.8 / prime 4608）
   - 相对口径（同一把尺子比较），不是 CoreMark/DMIPS 绝对值；DT dmips 不参与计算

7. **本文件与配置的范围**：本文件（soc.yaml/EEM）是 **sm8850 实测**；`feature.yaml`/`meta.yaml` 中的**调参参数（thermal/affinity/CLG/IO 等）全部沿用 sm8750 原值**，本次**未做** sm8850 专属实测调优——属"能跑起来"的沿用配置。

## 3. [efi] 单核功耗与簇功耗（逐档）

> 簇功耗 = idle + n×单核增量；单核功耗 = 簇功耗÷核数（见 §2.4）。算力 = capacity×f/f_max（相对）。
> **分段噪声**（合并后多轮标准差）：big 低频 10.7% / 中频 7.8% / 高频 7.9%；prime 低频 4.4% / 中频 4.1% / 高频 5.3%；boost 4.5%。

## 4. [limits] 边界与注意

- **boost 档（4512/4608）**：EPSS 动态 + 点状积热（3s 内 prime 点状温度 42→73°C）→ 3s 短测功耗波动 59-115%；**无降频**（cpuinfo=target）；boost 段为 10s 窗口中位，**仅参考**（不确定性 >20%）
- **低频段**：小信号（57-211mW），部分点噪声 10-16%（不影响形状/甜点）
- **甜点**（`sweet_index`：单核能效曲线 Δcap/Δpow≥1 的最后档）：big **2496 kHz** / prime **3859 kHz**（早期 V8 下 3513/4339；v14 修正高频后前移）
- **绝对量级**：qpt 纯 CPU 轨，不能直接与整板/电池对照
- §3 表数值复制自 `soc.yaml` 受控块；改块后本文件须同步再生（`frontier_policy.py --check`）

## 附录 B：与极客湾曲线转换（curve_anchor）的交叉验证

> 极客湾数据：socpk 8 Elite Gen 5（INT）公开数据，经 `curve_anchor.py` 锚点折算（整板口径，仅相对排序）。

| 路径 | 数据源 | 口径 | 形状对比（vs qpt 实测） |
|---|---|---|---|
| **qpt 实测（采用）** | PMIC 逐轨 | 纯 CPU 轨 | — |
| curve_anchor + 极客湾曲线 | 极客湾公开数据（整板） | 整板（含 DRAM/供电） | big **r=0.998** / prime **r=0.996**；平均偏离 2.1% / 3.9% |

**交叉点对比**：qpt **2.738 GHz** vs 极客湾 **2.738 GHz**（**完全一致**）。

**结论（采用 qpt 实测）**：
1. 纯 CPU 轨（EEM 需要的正是 CPU 簇功耗）
2. 直接测量（PMIC 逐轨，非二次折算）
3. 与 `frontier_policy.py` 完整前沿路径一致
4. 极客湾曲线转换（指纹 10c8e0774f175584）作交叉验证——形状一致，佐证 qpt 形状正确性（未采用）

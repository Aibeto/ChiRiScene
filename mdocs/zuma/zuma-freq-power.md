# zuma 频率与功耗对照（freqbench 实测）

> 索引：`[source]` `[caliber]` `[efi]` `[limits]`

- 功耗与算力来源：`freqbench_tensor/results/zuma/main/results.json`（zuma/main）。
- 口径：PMIC ODPM 逐轨净能量（无 `housekeeping` 键）：`active.power_mean` 已是该轨净功率，簇功耗 = n×active − (n−1)×idle（漏电校正）
- 定位：校准参照与前沿表的唯一数据源，不是运行期输入。生成器 `scripts/frontier_policy.py`
  读本文件 §3 的三张表，因此**三张表的表头与列序不可改**。
- 本文件由 `devimpbin/batch_ingest.py` 从 results.json 折算；密集核对见 [audit] 段。

## 2. [caliber] 折算口径

- 分支：`odpm`，无需减基线
- 簇功耗 `cluster_W = n × active − (n − 1) × 净idle`；算力 `coremark_score × n`。
- `active` 是「最忙单核 + 其余核空闲」的读数，乘核数会把同一份漏电重复计 n 次，故校正。

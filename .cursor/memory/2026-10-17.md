## 契约固化（已写入 agentsdocs/02-convention.md「日志」节）
- **级别契约**：error = 功能性失效/不可自愈/需人介入，**稳态不得出现**；warn = 可自愈/可降级/重试能恢复；info = 生命周期与状态迁移，低频；debug/trace = 每 tick/每帧/每事件高频。判级先问「失效会不会让某项能力静默丢失」，会则 error。
- **静默失效是首要敌人**：故障态与正常态在输出数据上同形最贵（FAS 即实例）。两条硬要求：① 读不到就写中性值/0/`-`/空表且产物会被离线分析当正常数据读 → 必须留痕；② 提前 return / continue / fallback / `let _ = write()` 若让能力局部或整体失效 → 必须留痕。
- **落点纪律**：高频路径必须 debug + `log_enabled!` 门控；周期性失败首次必报 + 每 N 次一条；翻转沿用状态位只报一次、恢复复位；启动期（logger::init 前）失败须 deferred 攒起、init 后补打（main.rs / rhine / 归档三处同款）。
- **禁忌**：i18n 内部与 logger 写路径内部不得调 t()/打日志（递归）。

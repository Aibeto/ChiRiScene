## 息屏保活锁（wake_guard）落地（用户 m01450 / m01467）

需求：加 wake_lock 兜底，**默认全机型关、仅 sm8750 默认开**；WebUI 开关放 **SceneMode 下方**。

### 改动
- 新增 `src/chiri/wake_guard.rs`（`[probe]``[sysfs]``[hold]``[release]`）：`WAKE_LOCK=/sys/power/wake_lock`、
  `WAKE_UNLOCK=/sys/power/wake_unlock`、`LOCK_NAME=chiri_screen_off`；`acquire/release/sync`；
  `AVAILABLE: OnceLock<bool>` 探一次、`HELD/WARNED: AtomicBool`（失败只告警一次，成功复位）；
  写节点用裸 `std::fs::write`（`utils::write_sysfs` 会 chmod 0664、`write_to_file` 写完改 0444，都不适合 /sys/power）。
- `src/chiri/mod.rs` 5 处：模块声明；循环初始化 `release("startup")`（清上一实例 SIGKILL 遗留）；
  screen 事件 `sync(enabled && !is_screen_on, "screen")`；`halted = down` 后 `sync(.. && !halted .., "down")`；
  `config_dirty` 块内 `sync(cfg.meta.wake_guard_enabled && !halted && !is_screen_on, "config")`（热重载即时生效）。
- 配置管道：`chiri::config::Meta.wake_guard_enabled`（`#[serde(default = "crate::common::default_wake_guard_enabled")]`）+
  `apply_meta_overrides` 用 `unwrap_or_else(default_wake_guard_enabled)`（**不能**写成 `if let Some`）；
  `common::ExternalMetaOverrides.wake_guard_enabled` + `MetaYamlFile.wake_guard_enabled` + `parse_disk_meta` 映射；
  新增 `common::default_wake_guard_enabled() = matched_soc_config_name() == Some("sm8750")`。
- 模板：`config/sm8750/meta.yaml` `wake_guard_enabled: true`（带代价注释）、根 `config/meta.yaml` `false`；其余 39 个 SoC 模板不写。
- i18n：`module/config/i18n/{zh,en}.ftl` 四个 key `scheduler-wake-guard-{hold,release,unavailable,failed}`。
- WebUI：`contract/meta.ts` 四处（META_FIELDS / WRITABLE_FIELDS / 布尔清单 / validateFieldValue 布尔 case）；
  `views/ConfigView.svelte` 加 `wakeGuardEnabled` derived（缺键回退 `app.configRel.startsWith('sm8750/')`，
  与 daemon 同口径）+ ToggleField 紧跟 SceneMode 之后；`i18n/locales/{zh,en}.ts` 两条文案。

### 关键判断
- **为何不能只写模板**：`sync_meta_snapshot` 对能过 `parse_disk_meta` 的磁盘 meta.yaml **原样不动**，
  老安装的 meta.yaml 不含新键也不会被补写 ⇒ sm8750「默认开」只能靠代码侧按机型判定。
- **为何不写内核超时**（`<name> <timeout>`）：单位在分支间秒/毫秒无保证，写错 = 静默提前释放，比不写更难查；
  改用启动盲释放 + 三处对齐 + 重启清除。
- **DOWN 语义**：停摆是"完全不干预"，保活锁必须松开，否则替系统扛着不让睡。

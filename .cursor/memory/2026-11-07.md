## 终末地性能优先档 `[perf_lock]`（用户 2026-11-07 03:23 直令）

- 指令原文：「先为终末地提供性能增强，要求忽略功耗开销，以绝对流畅、绝对不卡不掉帧，尤其是没有小卡顿为主要目标」。
- **为什么不纯改配置**：`controller.rs::effective_perf_floor()` 有 `.min(0.45)` 硬顶，`perf_floor` 写 1.0 也只得到 0.45，PID/稳态衰减仍把 `perf_index` 拉回 0.45 ⇒ 锁不住频。
- **做法**：新增 `perf_lock: bool`（缺省 false，逐应用显式开），在唯一下游 `policy_mgmt.rs::apply_freqs` 里 `perf_index = effective_perf = ceiling`。FAS 十二条降频路径（PID decay / steady decay / util 软封顶 / 开环 load_only / loading 0.60-0.70 / post_loading 0.65 / app_switch 0.60 / 齿轮机 min(0.90) / floor-rescue / post-jank floor / damped cap / thermal）全部只改 `perf_index`，写频必经此函数 ⇒ 一处收口。
- 配套：`load_only = !locked && uses_load_control()`（开环与锁频互斥）；`adjust_target_for_util` 与 `apply_steady_decay` 锁频档直接 return；`load_policies` 打 i18n `fas-perf-lock`；`reload_rules` 支持热重载。**顺序硬约束**：锁频写在 `thermal_cap` 之前，内核热限频仍可压顶。
- endfield.yaml 改：`perf_lock: true`、`fps_gears: [60.0]`（单档 ⇒ 齿轮机上下两段全不执行，掐掉「降档加速到 0.90」与「原生档 60↔120 翻面」）、per-app `target_fps: [60]`、`core_temp_threshold: 0.0` 保留。探针 grep 全仓确认无 `com.hypergryph.endfield` 本体日志（只有 arknights/skland）⇒ 本轮只能按机制设计，无现场标定。

## LTO 可配置化（用户 2026-11-07 05:03 直令：CI + 本地都启用 LTO）

- 指令口径：CI 默认全部 full LTO，其次 thin、off 回退（**按模块**）；本地构建询问一次用哪种（full/thin/off，**一次询问全部模块**）。
- 起点：主 crate 本来就是 full LTO（`[profile.release] lto = true`，自首个 xtask 提交 b8557f3），真实增量 = 档位显式化 + eBPF 模块纳入 + 本地询问 + CI 按模块回退。
- 关键事实：`CARGO_PROFILE_RELEASE_LTO=full` 被 rustc 拒绝（`incorrect value ... either a boolean ... thin, fat`）⇒ 用户口径 full 必须映射 `fat`；eBPF 目标（bpfel-unknown-none + build-std=core）三档都能链接，CI 预编译 bpf-linker v0.11.0 与本机 `.cache` 那份 md5 相同（`cae9c380…`，版本串都是 0.0.0），本地验证即 CI 同款工具链。
- 改动：`xtask/src/main.rs` 加 `[lto]` 段（`LtoLevel` full/thin/off、`cargo_value()` full→fat、`next()` 阶梯、`parse()` 别名；`LtoPlan::{Fixed,Auto}`；`resolve_lto` 优先级 CLI > `CHIRI_LTO` > auto；auto 且 stdin 是 TTY 且无 `CI` 才`ask_lto()`，否则按模块回退）；`build_core` 固定档直连、Auto 档循环 full/thin/off；`run_core` 用 `sh.push_env` 下发 `CARGO_PROFILE_RELEASE_LTO`/`CHIRI_LTO`/`CHIRI_LTO_FALLBACK`。`build.rs` 加 `lto_policy()` + eBPF 子构建重试循环（debug 强制 off；`CHIRI_LTO_FALLBACK=0` 时不回退）。根 `Cargo.toml` `lto = "fat"`。`scripts/build-arch/build-arch.sh` 的 `ask_lto` 询问一次并 export（`auto` 留给 xtask 判定）。CI 步骤 11 显式 `CHIRI_LTO: auto`。

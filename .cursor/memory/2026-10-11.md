## MemSearch 索引故障诊断与修复（2026-10-11，skill /memory-config）

**这是 MemSearch（@zilliz/memsearch-dsh 0.1.6）记忆配置，不是宿主 agent 自带的 memory/config 系统。**

- **症状**：`.memsearch/.index-state.json` 长期 `status: error`，`last_error = OpenAIError: Missing credentials...`；recall/inject 一直检索不到本项目记忆（milvus collection 从未建立）。

  1. 全局 `~/.memsearch/config.toml` **不存在** ⇒ `embedding.provider` 走内置默认 **openai**（`memsearch/config.py:58`），而本机只有 DEEPSEEK_API_KEY / HAPI_CN_API_KEY，**没有 OPENAI_API_KEY**。

- **为什么只能手动修**：memsearch 只认 `$HOME/.memsearch/config.toml`（`config.py:26` `expanduser()`，无任何 env 可重定向），`.memsearch.toml` 项目级被白名单过滤（`config.py:38-46`，只允许 milvus.collection / embedding.batch_size / chunking.* / indexing.* / watch.debounce_ms）；插件本身**从不传 `--provider`/`--model`**（`@zilliz/memsearch-dsh/index.js:382-402`），只传 `--default-collection` ⇒ 无法从插件侧绕过。

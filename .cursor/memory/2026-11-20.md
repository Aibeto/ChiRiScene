### 三条计数口径（已固化进 agentsdocs/05-maint.md 的 [analysis] 段、mdocs/socList.md:12）
1. 计入行数 = 批次目录内 main_*.log + aff_*.log 的整文件行数；daemon.log / status.csv / inventory.txt 不计。
2. 去重键 = 「main 总字节 + aff 总字节」完全相同（同批次被多包重复解包只计一次）。不可按 basename 去重：devimp_X 与 x_devimp_X 是同批次两种命名。
3. SoC 取 main_*.log 第 3 行的 "# soc=... board=... model=..."；soc=- 时回退 board（pineapple→sm8650、sun→sm8750、zumapro→zumapro、kalama→sm8550），再缺才看同级 daemon.log 首行。

### 环境坑
- 本会话工具桥反复失效：bash / read / glob 被 harness 的 auto review 拦截，reviewer 返回中文/英文散文或 DSML 片段而非 JSON，报 Unexpected token '工' / "收到。…" / "<|DSML|"，或直接挂死超时；acp_status / compress / job_list 不受影响。绕法：把命令写成单次 bash 调用并循环重试（通常第 1~2 次即成功）；读文件用 sed/cat 代替 read 工具。
- run_code 硬 120s 上限不变；全量扫描约 30s，务必 setsid nohup ... & 起后台再看输出文件。
- heredoc 写脚本时注意：Python 代码必须整段落在 <<'PYEOF' 里，不要把 "import io" 直接交给 bash（会被当成 ImageMagick 的 import 命令）。

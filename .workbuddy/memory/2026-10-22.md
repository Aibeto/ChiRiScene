# 2026-10-22

## WebUI 重构：玻璃拟态 → Fluent Design（流利设计）

- 目录：`webui/` 原样另存为 **`webui-blur/`**（留档，含 node_modules 硬链接），新建 `webui/` 由旧版源码派生。
  `build.rs` / `xtask` 只认 `webui/dist`，路径无需改。
- 设计系统重写：`src/app.css` 全量替换（token / 材质 / 原子类名）。类名做了 4 处重命名：
  `g-glass`→`g-acrylic`、`g-glass--flat`→`g-surface`、`g-sheen`→`g-reveal`、`g-grain`→`g-noise`；
  新增 `g-icon`、`g-card__sig`、`g-notice__signal`（信号从「左侧色条」改成「圆点 + 文字」）。
  token 改名：`--glass-*`→`--acrylic-*`/`--shadow-*`/`--surface-*`，`--champagne`→`--accent`，
  `--night*`→`--surface*`，`--spring`→`--ease`，`--motion` 500ms→200ms。
- 材质三层：Mica 场景（`.g-scene` #F3F2F1 + 单色光晕 + `.g-noise` 2%）→ Acrylic 浮层（顶栏/底栏/卡片/弹层）
  → 实心面 `.g-surface`（列表行/终端/快照表）。卡 hover `translateY(-4px)` + `--shadow-3`，按钮 hover -2px、
  `:active` `scale(.97)` + 阴影收起。
- 字体：拉丁改系统 **Segoe UI** 栈（不再加载 Poppins）；中文 Noto Sans SC 子集、等宽 JetBrains Mono 保留。
- 窄/宽屏：正文列 `max-width:720px` 居中，顶栏内距随列对齐，底栏限宽 520px。
- 风格闸门 `scripts/stylecheck.mjs` 重写为 Fluent 规则（禁止项 + 必须项 + 亚克力次数上限 + **g-* 类定义完整性检查**
  + DESIGN.md prop 契约校验 + span 宽高回归守卫）。DESIGN.md / README / `stylekit/fluent/`（3 个文件）同步重写；
  `agentsdocs/02-convention.md` 的 WebUI 样式分层小节整段更新。
- 构建兼容坑：WorkBuddy 注入的 fs shim 让 `fs.copyFileSync` 返回 EPERM，vite 的 `prepareOutDir` 复制 `public/`
  会直接失败。解决：删掉 `public/`，favicon 移入 `src/assets/` 走资产管线，`vite.config.ts` 设 `publicDir: false`。
  这同时让 dist 里每个文件都由 vite 生成，`[webui-embed]` 清单更干净。
- 验收：`npm run verify` 四步全绿（stylecheck 17 文件 / svelte-check 0 error / vitest 96 passed / build 成功）；
  另用 headless chromium 对比走查 420×900 与 1024×900 四屏，旧版同期截图确认 mock 长文本是既有行为。
- `.gitignore` 补 `webui-blur/` 各产物与 `.vscode` 例外、`webui/.shots/`。

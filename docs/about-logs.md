# 日志和遥测

在每次启动时会归档上次的运行日志和推理记录（若存在），两次启动时间间隔不足 30 秒时将会丢弃上次的运行日志。

## 导出日志

### 通过 WebUI 导出日志

建议先重启调度程序（点击 `Action` 按钮）然后打开 WebUI 点击 `导出历史日志` 按钮。
建议在导出完成后删除历史日志。

#### 手动保存日志

日志存放在以下位置：

- `/data/adb/modules/chiri/devimp`
- `/data/adb/modules/chiri/logd`
- `/data/adb/modules/chiri/logs`

## 日志级别和类型

### 日志级别

- `TRACE`
- `DEBUG`
- `INFO`
- `WARN`
- `ERROR`

### `云端AI推理记录许可` 开关

开启后将额外记录多组遥测数据用于改进调度
文件中不会包含任何可用于追踪的信息
日志不会自动上传，你需要手动将日志导出后提交给维护者

# 快速开始

## 检查可用性

### 检查内核

内核需要支持以下调速器：

- 以下调速器仅需支持任一：
  - uag（通常仅在 oplus 内核提供）
  - walt
  - schedutil
- 以下调速器必须支持：
  - performance

内核需要支持以下技术：

- eBPF

建议使用官方内核或已知行为的第三方内核，未知内核行为也可能造成问题

### 检查冲突

具有以下功能的其他程序可能会造成冲突：

- 对 CPU 频率和内核调速器调整
- 对线程亲和性进行调整
- 修改 Android Doze 逻辑和参数
- 伪装电池温度数据

## 获取 ChiRi

ChiRi 遵循 GPL v3 协议开源，代码托管于 [GitHub](https://github.com/Aibeto/ChiRiScene)

### 获取 Release

从 [GitHub Release](https://github.com/Aibeto/ChiRiScene/releases) 页面下载最新的稳定版。
由于稳定版均为经过多次验证的长期支持版本，与主线版本可能存在较大差异，所以 Release 不接受除了灾难性故障外的其他任何反馈。

### 获取 CI

从 [GitHub Actions](https://github.com/Aibeto/ChiRiScene/actions) 页面下载最新的 CI 构建版。
CI 构建版为最新的主线版本，仅经过初步功能验证，版本间行为差异较大。支持任何类型的反馈。

## 安装

### 全新安装

#### 普通安装（推荐）

和其他模块一样在管理器中选择压缩包安装。

#### 免重启安装（进阶）

:::warning
该方法为实验性方案，未经过完整验证
:::

1. 将压缩包中除了 `META-INF` 以外的其他文件和文件夹复制到 `/data/adb/modules/chiri` 目录下
2. 打开管理器，点击 `ChiRi` （不同版本名称不同，但通常都以 `ChiRi` 开头）模块的 `Action` 按钮

### 更新模块

#### 推荐的更新方式

> 部分版本不支持选择更新方式，刷入时将不提示选择更新方式，刷入完成后需要重启

> 音量键按下识别存在 1 秒左右延迟，延迟时间内重复按下将取消刷入

1. 在管理器中选择模块文件开始刷入
2. 在选择更新方式时选择 `热更新`
3. 在选择是否保留配置时选择不保留
4. 关闭刷入界面，点击模块的 `Action` 按钮

#### 其他更新选项

- 不选择 `热更新` 时，刷入完成后需要重启
- 选择 `保留配置` 时自定义设置将被保留，但部分版本可能会因冲突导致配置重置或调度程序退出
